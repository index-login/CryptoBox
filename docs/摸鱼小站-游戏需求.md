## ⛳ 一杆进洞（本期开发）

**风格方向**：不要求可爱，但要**耐看**——低饱和、有光影层次：黄昏渐变天空（深蓝→橘粉）、2-3 层远山剪影视差、低饱和草地色带、简洁旗杆、干净留白 UI、星子点缀（类似 Alto 系列的极简唯美）。

### 玩法（愤怒的小鸟式拉弓，一洞一杆制）

- **多杆制**：每洞限 3 杆（随关卡微涨），按住球往后拉发射，显示前半段预测轨迹 + 力度点；球停稳时在洞里 = 过关，不在就从停球点继续打下一杆（撞树弹回来不丢心，换个打法继续）；杆数用完丢一颗心并回发球台重打本洞；3 颗心丢完结束
- **果岭台**：洞位于凸起的窄平台中央（平台随关卡收窄 80→50），边缘会弹飞球；力度小上不了台、大则跳飞
- **障碍**：tee 与果岭之间立 🌲 高树，树干封贴地路线、树冠拦高抛弹道，撞树被弹开；数量随关卡 1→3
- **物理反赖皮**：坡度力（贴地上坡减速、下坡加速）、硬着陆掉速（冲击越大横向损失越大）、进洞速度门槛（滚太快 lip-out 跳过洞口）
- **地形**：程序生成（发球台平、中段丘陵幅度随关卡加大、果岭台），重试同一洞地形不变
- **相机与可视性**：画布顶部有**小地图条**（球/洞口/树的全程鸟瞰 + 实时距洞距离）；每洞开局和失败重置时，相机自动从洞口摇回发球台，先看清地形再打，杜绝盲打；果岭台右侧 260px 有隐形墙，球不会冲出地图
- **球种技能**：💗 滞空 / ⚡ 猛弹 / 🧲 磁吸 / 🌟 空中冲刺；过关掉落一颗随机特技球
- **计分**：过关 +100，剩余杆数每杆 +20，连击奖励（连续过关 n 洞每洞 +10×n），平稳进洞 +30；最高分 `moyu-golf-best`

### ⭐ 球种技能系统（像愤怒的小鸟：不同的球不同效果）

| 球种 | 图标 | 效果 |
|---|---|---|
| 标准球 | ⚪ | 默认，无限量 |
| 爱心球 | 💗 | 重力 ×0.6，轻飘飘滞空 |
| 闪电球 | ⚡ | 初速 ×1.4、弹性衰减减半，弹得更远 |
| 磁力球 | 🧲 | 距洞口一定范围内被吸向洞 |
| 星星球 | 🌟 | 飞行中可再点一次屏幕触发冲刺（当前速度 ×1.6，一杆一次） |

- **获取**：每完成一洞奖励 1 颗随机特技球（开局无）
- **选用**：发射前在底部球架条点选，当前球高亮 + 剩余数量角标；特技球用一次少一颗

### 规则与计分

- 每洞 par 杆（按洞距分 2/3/4），超过 par+2 丢一颗 ❤️（共 3 颗）；3 心丢完结束
- 得分 = 完成洞数 ×100 + 低于 par 奖励（-1 杆 +30）；一杆进洞全屏庆祝 toast
- 最高分 `moyu-golf-best`

## 🛡️ 熊熊保卫爱心（策略塔防）——需求级，细节待定

**核心循环**：小怪沿蜿蜒小路进攻底部的爱心巢 → 路旁固定建造格放萌宠炮塔 → 击杀得金 → 波次越来越强 → 无尽闯最高波数。

- **敌人**：👾 小怪 / 🦇 快速 / 🐷 坦克，每 5 波 👹 Boss；走到终点扣 1 颗心（共 3 颗）
- **炮塔**（初拟）：🐰 兔兔塔（快速单体）/ 🐱 猫猫塔（溅射）/ 🐸 青蛙塔（减速），可升级、可卖回
- **经济**：击杀得金、清波奖励、"提前召唤下一波"给额外金
- **计分**：存活波数 = 分数，最高波数存档；子弹用追踪光点（必中，免碰撞物理）
- **细节待定**：数值曲线、塔数量、建造 UI 形态（底部条 vs 弹层）、变速按钮

## 🏪 摸鱼奶茶铺（养成放置）——需求级，细节待定

**核心循环**：点 🧋 手动摇一杯 +钱 → 雇小动物店员自动产出 → 攒钱升级扩张 → 关掉页面也在赚钱（离线收益）→ 每天打开看店变大。

- **产出**：店员费用按经典放置曲线 ×1.15 递增；产出即"卖出杯数"，累计杯数是成长主指标
- **离线收益**：存档记 lastSeen，重新打开按离线时长结算（封顶 8h、效率 50%），欢迎语"你不在的时候店员卖了 X 杯"
- **里程碑**：100/1000/10000 杯…toast 彩蛋（"这店迟早开成连锁 🏪——林霞品牌"）
- **存档**：`moyu-shop-save` 每 5s + pagehide 保存；"重新开店"需确认
- **细节待定**：店员列表与人设、数值曲线、店铺等级解锁、界面布局（纯 DOM 无 canvas）
